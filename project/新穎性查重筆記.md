# 新穎性查重筆記（2026-07-05）

系統背景：ORB-SLAM3 fork，stereo-inertial，SuperPoint+LightGlue GPU ONNX 前端。
規則：MDPI 期刊不可當主要依據（僅標「證據弱」）；arXiv preprint 標「未過審」。

---

## 構想 1：信心加權 BA（LightGlue/SuperGlue 匹配信心 → 加權 reprojection error 的 information matrix）

**判定：部分重疊 — 「學習型不確定性加權 BA/殘差」這個大方向已相當擁擠，但「直接重用匹配器自身輸出的 confidence（而非另訓練專用不確定性頭）來加權經典 sparse indirect SLAM 的 keyframe BA」的具體組合未見直接先行工作。**

最接近先行工作：
1. **DROID-SLAM**（Teed & Deng, NeurIPS 2021, https://arxiv.org/abs/2108.10869）— dense/optical-flow confidence 加權 differentiable BA 殘差。差異：dense flow-based，非 sparse 學習型關鍵點匹配器信心；且是一體訓練的可微分 BA，非傳統 g2o/Ceres 後端。
2. **MAC-VO**（2024/2025, arXiv:2409.09479, IEEE 已刊）— 訓練 metrics-aware covariance 模型加權 pose graph optimization 殘差＋做關鍵點篩選。差異：covariance 是額外訓練出來的度量感知模型，不是 LightGlue 原生 match confidence；且僅是 VO（無迴環/全域 BA），非完整 SLAM 系統。
3. **CNN-Augmented VI-SLAM with Planar Constraints**（Ji et al., 2022, arXiv:2205.02940）— CNN 預測深度＋不確定性圖，加權 BA 中各特徵點貢獻。差異：CNN 不確定性頭與深度估計綁定，非匹配器信心分數；未指明 stereo 或用 LightGlue 類前端。
4. **RaCo**（Shenoi/Lindenberger/Sarlin/Pollefeys, 2026-02, arXiv:2602.15755, **preprint 未過審**）— 學習型關鍵點的協方差估計器，量化 metric-scale 空間不確定性。差異：評估侷限於 keypoint repeatability／two-view matching，未見整合進完整 SLAM BA 迴路的證據（原文摘要沒提）。

差異化建議（如果還要做）：明確主張「不額外訓練不確定性網路，直接複用 LightGlue 已輸出的 match confidence／SuperPoint detector score 做 information matrix 加權」，並在 ORB-SLAM3 classical keyframe BA（g2o）落地——把它定位成「零額外訓練成本的即插即用」而非「更準的不確定性模型」，這是與 MAC-VO/RaCo（都要訓練專用不確定性頭）的核心差異點。但审稿人大概率會要求跟 MAC-VO/CNN-Augmented VI-SLAM 做直接對比。

來源：
- https://arxiv.org/abs/2108.10869 (DROID-SLAM, NeurIPS 2021)
- https://arxiv.org/abs/2409.09479 (MAC-VO, 2024, IEEE)
- https://arxiv.org/pdf/2205.02940 (CNN-Augmented VI-SLAM, 2022)
- https://arxiv.org/abs/2602.15755 (RaCo, 2026-02, preprint)

## 構想 2：抽取閾值閉環控制（追蹤品質回饋 → 學習型抽取器偵測閾值自適應）

**判定：部分重疊，且重疊程度較高——「用某種回饋訊號自適應調整 SuperPoint 類學習型抽取器的關鍵點篩選/閾值」已有直接先例；「用追蹤品質（匹配數/內點率）做真正閉環控制」的窄化差異空間有限。**

最接近先行工作：
1. **SY-SLAM**（MDPI Sensors 2026，https://www.mdpi.com/1424-8220/26/11/3315，**MDPI，證據弱**）— TensorRT 部署 SuperPoint detector-only + adaptive SuperPoint keypoint 選擇策略：關鍵點充足時收緊篩選、稀缺時放寬，解決 feature starvation。差異：回饋訊號是「當前幀關鍵點數量」而非「追蹤品質（匹配/內點率）」的閉環；場景是動態室內 RGB-D + YOLOv8 人體遮罩，非 stereo-inertial 戶外/一般場景；且是 MDPI，證據等級低。
2. **SlimSLAM**（ASPLOS 2024，https://dl.acm.org/doi/10.1145/3620666.3651361）— 用 SLAM 內部狀態做領域特定回饋，動態調整演算法參數（含特徵相關參數）以節省算力，在 HybVIO 上示範，達 5.4x 加速且 iso-accuracy。差異：目標是「算力效率」而非「精度」，特徵抽取器是傳統（非學習型深度抽取器），且是參數排程（scheduling）非單一閾值的追蹤品質閉環。
3. **DK-SLAM**（Qu et al., 2024/2025, arXiv:2401.09160）— MAML 元學習關鍵點抽取＋coarse-to-fine tracking＋線上學習迴環。有「adaptive learning」但方向是跨場景泛化能力的元學習，不是即時追蹤品質回饋控制偵測閾值。
4. 已知基準（使用者已排除）：ALGD-ORB 等 ORB/FAST 自適應閾值（PMC10593235, PLOS ONE 2023）——僅適用經典特徵，非本構想比較對象但構成「這類想法本身不新」的背景壓力。

差異化建議：SY-SLAM 已經把「keypoint 數量回饋 → 調整 SuperPoint 篩選鬆緊」做掉了一半，且發表在 2026 年（與使用者投稿時間非常接近，需要在文獻回顧中明確引用切割）。要保留差異化，必須明確地把回饋訊號從「關鍵點數量」換成「下游追蹤品質指標（匹配內點率/重投影誤差分佈）」，且是真正的閉環（PID/比例控制或類似），並在 stereo-inertial 場景（非 RGB-D 室內）驗證。風險：這個窄化差異可能不足以撐起獨立賣點，建議與構想 1 或 3 合併成系統性貢獻，而非單獨成章。

來源：
- https://www.mdpi.com/1424-8220/26/11/3315 (SY-SLAM, 2026, MDPI)
- https://dl.acm.org/doi/10.1145/3620666.3651361 (SlimSLAM, ASPLOS 2024)
- https://arxiv.org/abs/2401.09160 (DK-SLAM, 2024)
- https://pmc.ncbi.nlm.nih.gov/articles/PMC10593235/ (ALGD-ORB, 已知基準)

## 構想 3：迴環一致性驗證（PCM 或學習型匹配信心統計當接受準則）

**判定：檢索範圍內未見直接先行工作——PCM 本身與其後繼方法（switchable constraints、GNC）在單機視覺 SLAM 的「迴環一致性驗證」語境下高度成熟，但specifically 是「PCM 風格的成對一致性檢查」用於單一機器人 ORB-SLAM3 類 Sim3 迴環接受準則、且以學習型匹配信心分數做統計判準，未查到直接對應論文。三者之中差異化空間最大。**

已試過的關鍵詞組合：`pairwise consistent measurement set maximization visual SLAM`、`PCM ORB-SLAM single agent outlier rejection Sim3`、`robust loop closure switchable constraints GNC single robot visual SLAM`。

最接近先行工作：
1. **PCM 原始論文**（Mangelson et al., ICRA 2018, http://robots.engin.umich.edu/publications/jmangelson-2018a.pdf）— 提出成對一致性測量集最大化，但設計目標是**多機器人地圖合併**的跨機器人迴環驗證（需要多條獨立回環假設互相檢驗一致性）。差異：單機器人 SLAM 中通常沒有多條獨立回環路徑可互相驗證，直接套用 PCM 需要重新設計「一致性集合」的定義來源（例如用多個候選迴環假設而非跨機器人測量）。
2. **Switchable Constraints for Robust Pose Graph SLAM**（Sünderhauf & Protzel, 2011-2013, https://nikosuenderhauf.github.io/projects/switchableConstraints/）— 單機器人/單後端最經典的錯誤迴環抑制方法，把每條迴環加開關變數，優化中自動關閉離群迴環。差異：這是十幾年前的通用後端方法，不使用學習型匹配信心，且已知存在「離群比例過高時失效」的限制（多篇後續文獻指出，如 AEROS）。
3. **AEROS: AdaptivE RObust Least-Squares for Graph-Based SLAM**（Frontiers in Robotics and AI, 2022, https://www.frontiersin.org/articles/10.3389/frobt.2022.789444/full）— 比較 SC/DCS/MM/GNC 等多種穩健估計器在圖優化 SLAM 中的表現，屬於同一代通用穩健後端家族，非視覺迴環信心特化。
4. **DOOR-SLAM / Kimera-Multi**（皆為多機器人系統）— PCM／distributed GNC 在多機器人場景的實際應用，進一步佐證 PCM 家族目前主戰場仍是多機器人，非單機視覺 SLAM。

差異化建議：可以清楚主張「把 PCM 的成對一致性思路搬到單機器人場景，用『同一段軌跡上不同時間窗產生的多個獨立迴環候選』互相做一致性檢驗，並用 LightGlue 匹配信心分數的統計量（而非單純幾何殘差）作為一致性判準的一部分」——這個組合（單機 PCM 改造 + 學習型匹配信心當判準）在檢索範圍內沒有撞見對應論文，是三個構想裡最乾淨的差異化空間。仍需注意：switchable constraints/GNC 這條路線非常成熟，論文需要清楚論證「為何 PCM 式離散一致性檢查比連續穩健估計器（GNC）更適合搭配學習型匹配信心」，否則審稿人會質疑「為何不直接用 GNC 加權」。

來源：
- http://robots.engin.umich.edu/publications/jmangelson-2018a.pdf (PCM, ICRA 2018)
- https://nikosuenderhauf.github.io/projects/switchableConstraints/ (Switchable Constraints, 2011-2013)
- https://www.frontiersin.org/articles/10.3389/frobt.2022.789444/full (AEROS, 2022)
- https://arxiv.org/pdf/2011.04087 (Kimera-Multi, 多機器人 GNC 對比)

## 總體風險排序（重疊程度高到低，即構想可行性風險高到低）

1. **構想 2（抽取閾值閉環控制）風險最高** — SY-SLAM（2026, MDPI）已做掉「SuperPoint 自適應篩選」的核心動作，差異化只剩「回饋訊號換成追蹤品質」這一個窄縫，且時間點非常接近，文獻回顧若漏引會被審稿人抓到。
2. **構想 1（信心加權 BA）風險中高** — 大方向（學習型不確定性加權 BA）已被 DROID-SLAM/MAC-VO/CNN-Augmented VI-SLAM 佔滿，但「直接複用匹配器原生 confidence、不額外訓練」的定位若講清楚可以站得住，需要正面對比 MAC-VO。
3. **構想 3（PCM 式迴環一致性驗證＋學習型信心判準）風險最低** — 檢索範圍內沒有直接撞車的論文，「PCM 從多機器人搬到單機器人＋學習型信心判準」的組合是三者中最乾淨的差異化空間，但要正面回應「為何不用更成熟的 GNC/switchable constraints」這個審稿人必問的問題。

建議：若要組成一篇論文，可以構想 3 當核心貢獻、構想 1 當輔助貢獻（信心加權 BA 提升前端精度），構想 2 風險最高、與 SY-SLAM 重疊最大，建議降級為次要 ablation 或直接捨棄，除非能明確找到 SY-SLAM 未覆蓋的场景（stereo-inertial、非室內動態場景）作為賣點。
