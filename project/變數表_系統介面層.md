## I. 一頁速記：變數「流向」對照

| 變數 | 從哪來 | 到哪去 |
| ---- | ------ | ------ |
| `vAcc/vGyro` | `LoadIMU` | 打包成 `IMU::Point` → `vImuMeas` |
| `vImuMeas` | main 逐幀組裝 | `TrackStereo` → `GrabImuData` |
| `imLeft/imRight` | `cv::imread` | `TrackStereo` → `imLeftToFeed` → `GrabImageStereo` |
| `mpAtlas` | System 建構子 `new` | 發配給 Tracking / LocalMapping / LoopClosing |
| `Tcw` | `mpTracker->GrabImageStereo` | TrackStereo 回傳（本 main 未接收） |
| `mTrackingState` 等 | `mpTracker->mState` | System 成員快照（鎖 `mMutexState`） |
